# Privacy and safety

EchoSafe is a local, single-user educational prototype. Text is submitted only when the user presses analyze. The API does not log raw text and does not save it automatically. History storage is an explicit opt-in request and can use local memory or optional MongoDB. There is no analytics SDK, hidden monitoring, alerting, authentication claim, or third-party API.

The model identifies language patterns learned from research datasets. It does not diagnose, assess suicide risk, or determine a person's emotional or clinical state. Confidence is model confidence and explanations are approximate occlusion interpretations. Users should not use outputs for high-impact decisions.
